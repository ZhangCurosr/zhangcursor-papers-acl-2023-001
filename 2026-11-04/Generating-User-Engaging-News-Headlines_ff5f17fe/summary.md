# 论文速读：Generating User-Engaging News Headlines

## 一句话总结
本文提出一个基于**签名短语（signature phrases）**的个性化新闻标题生成框架，利用对比学习从无标注用户阅读历史中提取与用户兴趣匹配的签名短语，并据此生成既吸引用户又忠于原文内容的个性化标题。

## 研究问题与动机
- **同标题分发策略的缺陷**：现有个性化新闻推荐系统（如Google News、Yahoo News）对所有用户展示相同标题，无法建立用户兴趣与推荐内容之间的可见关联，降低推荐效果。
- **个性化标题的约束挑战**：标题需同时满足（a）传达文章核心信息、（b）与用户阅读历史建立清晰联系，且平均仅约10个词，易滑向"标题党"或信息不足。
- **大规模标注数据缺失**：构建含新闻文章、多条个性化标题及对应用户画像的大规模数据集目前不可行，缺乏用于训练个性化标题生成模型的标注资源。
- **现有工作忽略个性化**：此前标题生成研究（Song et al., 2018; Xu et al., 2019; Matsumaru et al., 2020）主要聚焦准确摘要，未考虑个性化潜力。

## 核心贡献（创新点）
- **提出三步签名短语驱动框架**：先识别文章候选签名短语，再通过对比学习为用户选择兴趣相关短语，最后以这些短语为条件生成个性化标题；与既有工作的本质区别在于将"用户兴趣锚点"显式引入标题生成，而非直接编码完整历史。
- **无监督对比学习训练签名短语选择器**：利用合成用户数据和在批次对比损失（in-batch contrastive loss）训练编码器，无需人工标注即可学习签名短语与用户阅读历史的匹配关系；区别于PENS系列依赖人工标注或特定历史编码结构的方法。
- **合成用户（synthesized users）数据构建方案**：从现有新闻语料库通过"短语-文章映射+随机采样"模拟真实用户阅读历史，解决个性化标题训练数据稀缺问题；这是针对该任务的首创性数据合成策略。
- **综合自动化+人工的多维评估体系**：从用户适配度（H-U相关性、推荐分数）、文章忠实度（H-A相关性、FactCC）、文本质量三维度进行评估；超越传统ROUGE/BLEU单一自动指标，提供更贴近推荐场景的评估视角。

## 方法详解
框架由三个模块串联构成：

**3.1 签名短语识别（Signature Phrases Identification）**
- 任务形式化为条件文本生成：输入新闻文章或标题，输出所有候选签名短语（分号分隔）。
- 模型：在KPTimes数据集（279K条新闻-签名短语对）上预训练的BART模型。
- 损失：预测短语序列与人工标注序列之间的交叉熵损失。

**3.2 用户签名短语选择（User Signature Selection）**
- 输入：候选短语集$Z_d$、用户阅读历史$H_u = \{t_1, t_2, \dots\}$（已读标题集合）。
- 两种编码策略计算 engaging score：
  - **Holistic编码**：拼接所有历史标题，用整体历史编码器得向量$\mathbf{h}_u$，score = $\mathbf{z}_i^\top \mathbf{h}_u$（公式1）。
  - **Individual编码**：每个标题独立编码为$\mathbf{t}_j$，score = $\max_{t_j \in H_u} \mathbf{z}_i^\top \mathbf{t}_j$（公式2），取最大点积。
- 训练：in-batch对比学习，正对$(z_i, H_i)$、负对$(z_i, H_j)$，损失为InfoNCE形式（公式3-4）：
  $$L_{select} = \frac{1}{2}\left(\sum_i \log \frac{S(z_i, H_i)}{\sum_j S(z_i, H_j)} + \sum_j \log \frac{S(z_j, H_j)}{\sum_i S(z_i, H_j)}\right)$$
- 筛选：取score最高的top-k个短语作为用户签名短语$Z_d^u$。

**3.3 签名导向标题生成（Signature-Oriented Headline Generation）**
- 输入：新闻文章$d$ + 用户签名短语$Z_d^u$；输出：个性化标题$t$。
- 模型：BART-large。
- 训练损失：条件语言模型负对数似然（公式5）：
  $$L_{gen} = -\sum_i \log \text{Pr}(w_i | w_1, \dots, w_{i-1}; Z_d^u, d)$$
- 训练时$Z_d^u$从ground-truth标题反推；推理时从文章本身识别并选择。

**数据合成（Corpora Processing）**
- 使用Newsroom和Gigaword两语料库。
- 合成用户创建流程：识别所有文章签名短语→建立短语-文章映射→随机采样短语作为用户兴趣→从对应文章中采样标题构建阅读历史。
- 训练时每用户分配1个兴趣短语（对比学习需要）；评估时分配1~5个以模拟真实场景。

## 实验与结果
**数据集**：Newsroom（训练995K/验证58K/测试109K）和Gigaword（训练7.7M/验证394K/测试381K）。

**基线方法**：
- PENS-NRMS / PENS-EBNR（Ao et al., 2021，LSTM-based个性化标题生成）
- Vanilla System（BART-large直接微调，无签名短语）
- Vanilla Human（人工原标题）
- SP-headline / SP-random（使用原標題/随机签名短语引导生成）
- SP-holistic / SP-individual（本文方法，含-naive DPR编码和-fine-tuned版本）

**评估指标**：
- 用户适配：H-U相关性（DPR点积、SBERT余弦）、新闻推荐分数（基于MIND训练的推荐系统）
- 文章忠实：H-A相关性（DPR/SBERT）、FactCC事实一致性比例
- 其他：ROUGE-L F1、Extractive Coverage、标题长度

**主要结果（Newsroom）**：
- SP individual-F最优：H-U DPR=**55.05**，REC Score=**2.947**，FactCC=**69.5%**；显著超越PENS-EBNR（DPR 50.89，REC 2.476）和Vanilla System（DPR 51.78，REC 2.697）。
- 签名短语选择器评估：Individual-F在Hit@1上达**40.34%**，Mean Rank=**2.395**，显著优于Random（9.28%）和Holistic-F（30.10%）。
- GPT-3对比：SP individual-F在REC Score（4.618 vs 4.562）和H-U DPR（54.75 vs 52.73）上均优于Topic-Oriented GPT-3。

**主要结论**：
- Individual编码策略优于Holistic策略（更精确捕捉用户单篇历史兴趣）。
- Fine-tuned编码器（-F）显著优于naive DPR（-N）。
- 随机签名短语选择性能接近Vanilla System，证明有效选择是个性化的关键。
- 用户兴趣短语数增加时，用户适配分数下降（表5），但即使30个兴趣仍优于Vanilla。

**人工评估（16名评估者，12篇文章）**：SP-individual-F在用户适配维度得分最高，文本质量与人工标题相当（约1.8/2）。

## 相关工作脉络
- **PENS (Ao et al., 2021)**：首个个性化新闻标题数据集和框架，使用LSTM+注意力编码用户历史；本文定位差异在于引入"签名短语"作为兴趣中介，避免直接处理长历史序列，且无需标注数据训练选择器。
- **自动标题生成（Song et al., 2018, 2020, 2021; Matsumaru et al., 2020）**：聚焦于从文章到标题的摘要生成，未考虑用户个性化；本文在此基础上注入用户兴趣信号。
- **个性化内容生成（Majumder et al., 2019; Wu et al., 2021b; Dudy et al., 2021）**：涉及个性化食谱、对话回复等；本文将个性化机制引入新闻标题生成，并设计专门的签名短语选择策略。
- **KPTimes签名短语数据集（Gallina et al., 2019）**：279K新闻-签名短语对，本文在此预训练签名短语识别模块；此前此类数据集主要针对学术论文关键词提取。
- **GPT-3零样本摘要（Goyal et al., 2022）**：展示大模型在零样本设置下的摘要能力；本文证明任务专用微调模型仍显著优于GPT-3 prompt方法（在个性化场景下）。
- **DPR对比学习（Karpukhin et al., 2020; Radford et al., 2021）**：信息检索领域的对比学习范式；本文将其迁移至签名短语-用户历史的匹配学习任务。

## 局限性与未来方向
- **数据偏差与回声室风险**：模型可能强化用户已有兴趣，产生信息茧房（论文Section 7自述）；训练数据若存在偏差会导致输出不准确或误导。
- **多签名短语引入事实错误**：当输入多个签名短语时，生成器可能被强迫将不相关短语纳入标题，导致事实性错误（如Table 3示例1）。
- **兴趣短语数量敏感性**：用户兴趣短语越多，个性化效果越弱（表5显示30个兴趣时DPR降至53.14 vs 1个兴趣的55.63）。
- **合成数据的真实性局限**：使用合成用户而非真实用户数据，可能无法完全模拟真实用户行为分布。
- **未来方向**：探索更鲁棒的多兴趣聚合方式、引入多样性正则化缓解回声室效应、在真实用户数据上验证。

## 研究启发与可借鉴点
- **对比学习用于个性化匹配**：in-batch contrastive loss是无标注个性化数据训练的有效范式，可迁移至其他个性化生成任务（如个性化摘要、推荐解释生成）。
- **"中介表征"设计思路**：通过签名短语将用户历史压缩为有限兴趣锚点，而非直接输入原始历史，既降低计算开销又提升可解释性；此思路适用于任何"用户偏好→生成条件"的映射任务。
- **合成数据策略**：短语-文章映射+随机采样构建合成用户的方法，为缺乏标注数据的个性化生成任务提供了可复用的数据构建范式。
- **多维评估框架**：同时评估用户适配度和文章忠实度（而非仅关注自动指标），避免了"个性化但脱离原文"或"忠实但无个性"的极端；该评估范式可扩展至其他个性化文本生成任务。
- **与大模型结合的空间**：本文GPT-3实验表明任务专用模型仍优于zero-shot prompt，但"Topic-Oriented"提示策略有效利用了签名短语选择结果，提示未来可探索小模型选择+大模型生成的混合架构。

## 关键术语表
- **Signature Phrase（签名短语）**：从新闻文章中提取的、能代表文章核心主题或实体的短语，用于作为用户兴趣锚点和标题生成条件。
- **Synthesized User（合成用户）**：通过从新闻语料中随机采样短语和文章构建的虚拟用户画像，用于在无真实用户数据情况下训练和评估个性化模型。
- **In-batch Contrastive Learning（批次内对比学习）**：在一个batch内将正对（同一用户的签名短语与阅读历史）与其他负对区分开的对比学习训练策略。
- **H-U Relevance（Headline-User相关性）**：生成标题与用户签名短语之间的语义相似度，衡量个性化适配程度。
- **H-A Relevance（Headline-Article相关性）**：生成标题与原文之间的语义相似度，衡量标题对原文的忠实度。
- **FactCC**：基于预训练模型的事实一致性评估工具，判断生成文本是否与源文本存在事实冲突。
- **REC Score（推荐分数）**：通过训练的新闻推荐系统（基于MIND）对用户历史和标题计算的重定向推荐得分。
- **Extractive Coverage（抽取覆盖率）**：生成标题中来源于原文的词语比例，衡量标题的抽取程度。

## 可复现要素
- **数据集**：Newsroom和Gigaword为公开数据集；KPTimes为公开数据集。本文使用的合成用户数据基于上述公开数据构建。
- **代码/权重**：论文未明确提供代码开源链接（致谢中提及PENS使用其github repo，GPT-3使用OpenAI API，DPR/Sentence-BERT/FactCC使用各自公开仓库）；BART-large和DPR模型来自HuggingFace。
- **关键超参**：签名短语选择——batch size 96×8，lr 3e-5，15 epochs，签名短语max length 16 tokens，标题max 48 tokens，历史max 256 tokens；标题生成——batch size 48×8，lr 5e-5，6 epochs，文章max 512 tokens，历史max 256 tokens（详见Appendix Table 8）。
