# 论文速读：Alleviating-Over-smoothing-for-Unsupervised-Sentence-Represe

## 一句话总结
本文针对无监督句子表示学习中普遍存在的**层间过平滑**（inter-layer over-smoothing）现象，提出了一种即插即用的简单自对比学习框架 **SSCL**，通过直接复用 PLM 中间层的隐藏表征作为负样本，有效拉开最终层与中间层表征的距离，在 7 个 STS 与 7 个 Transfer 数据集上显著提升了 BERT 与 SimCSE 等主流基线的句子表示质量。

## 研究问题与动机
- **层间过平滑制约 PLM 容量发挥**：实验观察到，在 SimCSE 等先进无监督句子编码器中，随着 Transformer 层数加深，相邻层的句子表征余弦相似度普遍 >0.9，表明深层未能学到足够区分的语义知识，导致网络有效容量与判别力下降。
- **现有方法偏重正样本构造、忽视负样本挖掘**：主流对比学习工作（如 SimCSE、Consert、CLEAR）主要通过 Dropout、词删除等数据增强手段构建正样本对，但负样本仍依赖批次内随机采样，缺乏针对模型内部表征冗余的系统性优化。
- **截断层数并非可行解**：直接移除最后若干层虽可降低层间相似度，但会不可逆地损失模型容量（如 SimCSE 去掉最后两层后 STS-B 得分从 76.85 降至 70.45），亟需从训练目标层面进行修复。
- **过平滑与各向异性（anisotropy）常被混淆**：各向异性描述的是所有句子表征全局分布过于集中；而过平滑描述的是同一句子在不同层或不同 token 之间趋于同质化，两者机理不同，现有 Whitening/Flow 类方法未能直接缓解层间冗余。

## 核心贡献（创新点）
- **首次系统揭示并形式化“层间过平滑”问题**：通过定义 SetSim 指标，量化指出当前 SOTA 无监督句子编码器存在严重的相邻层表征同质化，填补了 PLM 表示诊断的一个空白。
- **提出 SSCL（Simple Self-Contrastive Learning）即插即用框架**：仅利用同一 PLM 中间层的输出作为额外负样本注入对比损失，无需引入复杂的数据增强管线或外部难负样本生成器，实现成本低且兼容性强。
- **证明层间过平滑缓解可同步改善层内过平滑**：通过 TokSim 分析与可视化表明，压制相邻层相似度能打破 token 表征的过度聚集，使句子级与词元级表示均更具判别力。
- **揭示优质表征对向量维度的依赖性可降低**：实验显示 SSCL 在将向量维度从 768 压缩至 256 时不仅未损失性能，反而在 BERT 基线上取得更好结果（62.42% vs 58.83%），说明方法有效剥离了冗余语义信息。

## 方法详解
- **层间相似度度量（SetSim）**：设 $s_i$ 与 $s_{i+1}$ 为句子 $X$ 在 PLM 第 $i$ 与 $i+1$ 层输出的句子向量，则 $\mathrm{SetSim} = \frac{s_i^\top s_{i+1}}{\|s_i\|_2 \|s_{i+1}\|_2}$，用于监控过平滑程度。
- **传统对比学习目标回顾**：标准 InfoNCE 损失 $\mathcal{L}_{\mathrm{tcm}} = -\log \frac{\exp(\Psi(h_i, h_i^+)/\tau)}{\sum_{j=1}^{N} \exp(\Psi(h_i, h_j)/\tau)}$，仅依靠批次内随机样本作为负样本，未利用模型内部结构信息。
- **SSCL 损失函数设计**：在分母中额外加入中间层负样本项，重构为 $\mathcal{L} = -\log \frac{\exp(\Psi(h_i, h_i^+)/\tau)}{\sum_{j=1}^N \exp(\Psi(h_i, h_j)/\tau) + \exp(\Psi(h_i, h_i^-)/\tau)}$，其中 $h_i^-$ 为第 $M$ 层中间层输出。该设计强制最终层表征远离所有被采样的中间层表征。
- **Progressive SSCL 扩展**：将连续的多层中间表征（如第 10、11 层）堆叠共同构成负样本集，实验表明堆叠 2 层可获得最优 STS 平均性能（77.90%），说明适度增加负样本多样性比单纯扩大 batch size 更有效。
- **工程兼容性**：正样本构造完全继承原有数据增强策略（如 SimCSE 的 dropout mask），SSCL 仅修改对比损失的分母项，训练流程、优化器与超参设置无需大幅调整。

## 实验与结果
- **评估套件**：7 个 STS 任务（STS12-16, STS-B, SICK-R，指标为 Spearman 相关系数）与 7 个 Transfer 任务（MR, CR, SUBJ, MPQA, SST-2, TREC, MRPC，指标为分类准确率），统一使用 SentEval 评估。
- **主要基线**：GloVe、SkipThought、BERT (base/large)、BERT-flow、BERT-whitening、IS-BERT、CT-BERT、Consert、SimCSE。
- **STS 任务最强结果**：SSCL-SimCSE_base 平均得分 **77.90%**（较 SimCSE_base 提升 **1.65%**）；SSCL-SimCSE_large 平均得分 **79.69%**（较 SimCSE_large 提升 **2.16%**）。在 BERT 基线上，SSCL-BERT_base 平均达 **62.42%**，较原始 BERT (46.70%) 提升约 **15.68%**。
- **Transfer 任务结果**：SSCL-SimCSE_large 在 7 个下游任务上全面超越 SimCSE_large，平均准确率由 87.17% 提升至 **88.88%**，且在 MR、CR、SST-2、TREC 等细分数据集上均创同类 encoder 最高分。
- **关键数值支撑**：负样本层选择实验中，取第 11 层（倒数第二层）作为 $h_i^-$ 时 STS 平均性能最优；温度 $\tau=0.05$ 时模型收敛最快且效果最佳；仅将 batch size 从 64 翻倍至 128 无法复现同等增益，证明提升来源于负样本质量而非数量。

## 相关工作脉络
- **SimCSE (Gao et al., 2021)**：开创性提出用 Dropout 构造正样本的无监督句子对比学习方法；本文与其定位差异在于 SimCSE 聚焦正样本构建，而 SSCL 专注于补全对比学习中被忽视的负样本侧，两者可叠加使用。
- **BERT-whitening / BERT-flow (Li et al., 2020; Su et al., 2021)**：通过后处理线性变换缓解各向异性；本文从训练目标层面根除层间冗余，无需额外的投影头或协方差白化操作，更适合端到端部署。
- **Consert / CT-BERT (Yan et al., 2021; Carlsson et al., 2021)**：强调难负样本挖掘或对比张力机制；本文的负样本完全源自同一模型内部中间层，零外部语料依赖，实现更轻量且避免难负样本带来的训练不稳定风险。
- **Over-smoothing in BERT (Shi et al., 2022)**：从图卷积视角分析层内 token 表征同质化；本文首次将过平滑概念正式延伸至层间句子级别，并揭示层间与层内过平滑存在隐式正向反馈关系。

## 局限性与未来方向
- 当前验证仅覆盖英文无监督场景，跨语言句子表示或低资源语言下的泛化能力尚未检验。
- 训练语料固定为 Wikipedia 单语数据，在特定领域（如医学、法律）或带有社会偏见的数据上可能引入偏差，限制其在检索系统中的直接部署。
- 负样本层的选择依赖网格搜索（本文固定推荐倒数第二层），缺乏自适应或多尺度层负样本的动态路由机制。
- 未来可将该思想迁移至 RoBERTa/DeBERTa 等架构、段落级表示学习，或与软负样本（SNCSE）、多模态对比学习结合探索更通用的内部负样本挖掘范式。

## 研究启发与可借鉴点
- **“内部负样本”挖掘范式**：无需外部对抗生成器或硬负样本检索，直接从模型自身中间层提取负样本即可显著提升对比学习效果，该思路可迁移至词嵌入、代码表示、图谱实体表示等任务。
- **过平滑诊断指标的联动使用**：SetSim 与 TokSim 可作为日常实验中的快速诊断工具，帮助科研团队判断 PLM 是否陷入表征同质化陷阱，指导网络深度、正则化强度或对比损失的调优。
- **降维鲁棒性实验设计**：结合维度压缩消融验证表征质量是一种高信息密度的实验策略，能直观体现
