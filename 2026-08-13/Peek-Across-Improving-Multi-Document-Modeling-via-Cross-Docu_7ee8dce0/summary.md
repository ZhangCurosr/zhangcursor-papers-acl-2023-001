# 论文速读：Peek-Across: Improving Multi-Document Modeling via Cross-Document Question-Answering

## 一句话总结
本文提出了一种基于跨文档问答的新型多文档预训练目标，模型需要在"窥探"其他相关文档的前提下生成答案并恢复源句子，从而更好地学习跨文档信息关系。该方法生成的模型 QAMDEN 在多文档问答、摘要等多个任务上显著提升性能，并大幅优于零样本 GPT-3.5/GPT-4。

## 研究问题与动机
1. **现有模型面向单文本而非多文本**：大多数NLP模型设计用于处理单一文档，难以有效整合分散在多个文档中的信息，导致多文档任务（如多文档摘要、跨文档QA）性能受限。
2. **已有预训练目标存在任务局限**：现有跨文档预训练方法（如CDLM、PRIMERA）要么仅适用于分类任务，要么主要面向摘要任务，缺乏能同时支持短文本生成（QA）和长文本生成（摘要）的通用目标。
3. **预训练数据规模受文档聚类数量限制**：现有方法的预训练实例数与可用文档聚类数成正比（如PRIMERA的367K实例），难以高效扩展；本文通过单文档QA生成实现了数据的"一簇多视"扩充（3.57M实例）。
4. **多文档场景下的信息整合能力不足**：现有方法在捕捉细粒度（单个谓词-论元关系）和粗粒度（跨文档整体信息流）关系方面存在局限，缺乏有效的机制引导模型"偷看"其他文档。

## 核心贡献（创新点）
1. **跨文档问答预训练目标**：提出将多文档预训练扩展为跨文档QA任务，模型需基于其他文档生成答案并恢复源句子；与CDLM等仅做分类/掩码恢复的方法不同，本文目标同时支持长短文本生成，具有更强的任务通用性。
2. **可控的高质量QA数据生成管线**：利用QASEM语义解析框架从显要句子自动生成QA对，并选取最长答案；与PRIMERA的无控制掩码句子生成相比，本文QA目标具有语义可控性，可减少幻觉。
3. **三种互补的数据生成模式**：设计模式(a)排除源文档、(b)屏蔽显要句子、(c)仅屏蔽答案三个变体，分别从不同信息遮蔽程度引导模型学习跨文档关系；现有方法仅提供单一视角（如PRIMERA仅屏蔽句子）。
4. **大规模数据扩充**：每个文档聚类平均生成3.5个实例，将367K聚类扩展至4.3M预训练实例；相比PRIMERA的同量级数据，本文实现了十余倍的数据扩增，且无需额外人工标注。
5. **全面的基准验证与LLM对比**：在6个多文档任务上系统性验证，QAMDEN在多数任务上超越SOTA，且在零样本设置下大幅领先GPT-3.5/GPT-4。

## 方法详解
**模型基础架构**：以Longformer-Encoder-Decoder（LED，447M参数）为骨干，编码器使用局部滑动窗口注意力（窗口大小1024）+全局注意力（<doc-sep>标记），输入长度4096，输出长度1024。

**显要句子选择（CD-GSG）**：对文档聚类S中的每篇文档D_k，计算其最显要句子s_k^*，采用跨文档ROUGE评分：
`CD-GSG-Score(s_k^i) = ROUGE(s_k^i, S/\{s_k^i\})`，即在句子与其所在文档其余部分及其他所有文档之间的重叠度。

**QA生成管线**：
1. 用QASEM（基于T5-small的语义解析器）对显要句子生成多个谓词-论元QA对；
2. 选择答案最长的那对(q_k^*, a_k^*)；
3. 用Pyatkin et al. (2021)的上下文化模型将QASEM生成的占位符式问题转化为自然语言问题。

**三种预训练数据模式**（Algorithm 1）：
- **模式(a)**：排除源文档D_k，输入为[S_n/D_k, q_k^*]，目标为[a_k^*, s_k^*]——最具挑战性，迫使模型从其他文档推理。
- **模式(b)**：源文档完整但屏蔽显要句子，输入为[S_n/{s_k^*}, q_k^*]，目标为[a_k^*, s_k^*]。
- **模式(c)**：仅屏蔽答案，输入为[S_n/{a_k^*}, q_k^*]，目标为[a_k^*, s_k^*]。

**训练目标**：输出格式为`answer, sentence`，即先生成答案再生成源句子。这种设计引入复制机制（直接拷贝源文本）和长文本生成能力，对摘要任务尤为关键。

**超参数**：Adam优化器，lr=3e-5，10k warmup + linear decay，batch size=16，共400k步，8×48GB RTX8000 GPU约8天。

## 实验与结果
**数据集**：预训练使用NewSHead语料（367K文档聚类）；评测涵盖6个下游任务。

**多文档QA**（Table 2）：
- HotpotQA-distractor：QAMDEN F1=67.1 / EM=52.7，超越PRIMERA（65.4/47.8）和LongT5-xl（66.1/50.9）。
- WikiHop：QAMDEN F1=69.3 / EM=65.2，超越PRIMERA（65.0/61.9）和LongT5-xl（67.7/63.6）。

**多文档摘要 MDS**（Table 3-4）：
- Multi-News：QAMDEN R-1=50.9 / R-2=23.1 / R-L=27.2，超越PRIMERA（49.9/21.1/25.9）和Pasunuru et al.（49.2/19.6/24.5）。
- Multi-XScience：QAMDEN R-1=33.5 / R-2=7.6 / R-L=19.1，略低于LongT5-xl（33.7/8.1/19.4），但优于PRIMERA（31.9/7.4/18.0）。

**查询焦点多文档摘要 QMDS**（Table 5-6）：
- QMDSCNN：QAMDEN R-1=38.8 / R-2=18.3 / R-L=37.2，超越PRIMERA（36.1/16.2/35.7）。
- QMDSIR：QAMDEN R-1=47.6 / R-2=25.1 / R-L=42.4，超越PRIMERA（45.7/23.6/40.9）。

**与LLM对比**（Table 8）：在Multi-News 200实例子集上零样本测试，QAMDEN R-1=45.3显著超过GPT-3.5（36.4）和GPT-4（34.7）。人工评估（Table 9）显示QAMDEN在内容、可读性、非冗余性三项上均获更高偏好率。

**消融要点**（Figure 4 & Table 7）：三模式联合训练效果最优；模式(c)对QA最有效（抽取式），模式(a)对摘要最有效（抽象式）；去掉显要句子生成导致摘要性能显著下降；QASEM优于其他QA生成器。

## 相关工作脉络
1. **CDLM（Caciularu et al., 2021）**：首个跨文档预训练模型，用Longformer编码器在多文档聚类上做token掩码预测，但仅适用于分类任务；本文扩展至seq2seq生成任务。
2. **PRIMERA（Xiao et al., 2022）**：最接近的基线，同样基于LED，使用金字塔估计算法选择显要句子并做掩码句子生成；但PRIMERA生成无控制且数据量仅367K，本文用QA目标引入可控生成和数据扩增。
3. **PEGASUS（Zhang et al., 2020）**：单文档GSG预训练方法，用ROUGE选显要句子做gap填充；本文将其推广至跨文档场景（CD-GSG）。
4. **LinkBERT（Yasunaga et al., 2022）**：利用Wikipedia超链接构建相关文档对进行预训练；本文聚焦同一事件聚类内的文档间关系建模。
5. **QuASE/CCQA（He et al., 2020; Huber et al., 2022）**：利用生成QA数据进行预训练以提升上下文表征；本文首次将QA预训练引入多文档设置，并强调跨文档信息整合。
6. **LongT5-xl（Guo et al., 2022）**：3B参数的长上下文seq2seq模型；本文447M参数的QAMDEN在其多个任务上实现超越，体现了预训练目标设计的重要性。

## 局限性与未来方向
1. **事实一致性问题**：未微调的QAMDEN可能产生幻觉或事实不一致的输出，尤其在生成类任务中无法保证准确性。
2. **QASEM的质量瓶颈**：QASEM可能生成不恰当的问题，尽管尝试了过滤策略但效果不佳；噪声问题直接影响预训练质量。
3. **领域覆盖有限**：预训练数据来源于NewsHead新闻语料，而评测数据集涉及科学文献等不同领域，领域迁移可能受限。
4. **单文档触发跨文档关系的机制待深化**：当前仅通过单句QA生成触发跨文档整合，如何利用多篇文档间的更复杂关系尚待探索。
5. **对不相关/单文档场景的泛化未知**：模型专门针对相关文档聚类设计，在出域场景下的表现可能不理想。

**未来方向**：（1）将跨文档QA预训练拓展到Decoder-only大型LM，结合in-context learning和prompt tuning；（2）在检索增强语言模型（RALM）设置中应用，将相关文档作为外部非参数化知识库；（3）探索更复杂的跨文档关系建模（如事件共指、时序推理）。

## 研究启发与可借鉴点
1. **"一簇多视"数据扩增范式**：从单一文档聚类通过QA生成衍生出多种预训练样本，为数据稀缺的多文档任务提供了高效的数据扩充思路，可迁移至其他需要多文档上下文建模的任务（如事件检测、知识图谱构建）。
2. **QA目标驱动的细粒度语义学习**：用谓词-论元级别的QA生成引导模型关注句子内部的核心语义单元，这种细粒度信号可与粗粒度的文档级关系相结合，值得在信息抽取、语义角色标注等任务中探索。
3. **三种遮蔽模式的互补性设计**：排除源文档（最强跨文档推理）、屏蔽句子（中等）、屏蔽答案（较弱）形成难度梯度，这种由易到难或由弱到强的多模式混合训练策略可在其他预训练目标设计中复用。
4. **生成源句子的"复制机制"价值**：消融实验证明让模型生成答案后紧接着生成源句子对摘要任务至关重要——这一设计启示我们，在需要忠实于源文本的生成任务中，显式引入"生成-复制"双重目标是有价值的。
5. **与LLM的零样本对比验证范式**：将小规模精调模型与GPT-3.5/4在零样本设置下对比，展示了领域适配预训练的价值，这一评测策略可为其他专用模型提供有说服力的对比基准。

## 关键术语表
**Cross-Document Question Answering（跨文档问答）**：需要从多篇相关文档中检索、整合信息才能回答的问答任务，要求模型具备跨文档推理能力。
**QAMDEN（Question-Answering-based Multi-DocumENt）**：本文提出的多文档语言模型，以LED为架构，通过跨文档QA预训练获得。
**CD-GSG（Cross-Document Gap Sentence Generation）**：本文提出的跨文档显要句子选择方法，用句子与其余文档的ROUGE重叠度评分。
**QASEM**：一种基于语义解析的问答生成框架，将句子中的谓词-论元关系自动转化为QA对，本文选用其生成交叉文档预训练数据。
**Longformer Encoder-Decoder（LED）**：结合Longformer局部+全局注意力机制的encoder-decoder架构，支持长文档输入，本文以此为基础模型。
**NewSHead**：一个多文档聚类语料库，包含新闻文章及其对应的headline，本文预训练数据来源于此。
**Mode (a)/(b)/(c)**：三种预训练数据生成模式，分别对应排除源文档、屏蔽显要句子、仅屏蔽答案的不同信息遮蔽策略。
**Zero-shot GPT-3.5/GPT-4**：未经微调直接通过API调用GPT-3.5/GPT-4进行多文档摘要任务，本文用于与QAMDEN对比的大型语言模型基线。
