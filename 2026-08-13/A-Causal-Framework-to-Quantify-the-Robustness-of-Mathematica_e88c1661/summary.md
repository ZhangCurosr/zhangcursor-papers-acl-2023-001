# 论文速读：A-Causal-Framework-to-Quantify-the-Robustness-of-Mathematical-Reasoning-with-Language-Models

## 一句话总结
本文提出一个基于因果推断的行为测试框架，通过 do 干预分离输入中数值操作数（N）、文本表面形式（S）和运算符（O）对语言模型数学推理预测的因果效应，从而同时量化模型的**敏感性**（对正确答案变化的响应能力）与**鲁棒性**（对不影响答案的扰动保持稳定），并在 GPT 系列与 LLaMA 系列模型上进行系统评测。

## 研究问题与动机
- **核心问题**：LLM 在数学推理任务上的高分是否意味着真正掌握了数学概念，还是仅依赖训练数据中的浅层模式/虚假相关？
- **现有方法不足**：既往鲁棒性分析（如 Patel et al., 2021）依赖人工构造问题变体，缺乏原则化、可量化的因果框架来分离不同输入因素的独立效应。
- **度量缺口**：现有工作主要报告准确率，缺少对模型"为何正确/错误"的行为学分解——例如模型是依赖运算逻辑，还是记住了特定数字组合。
- **规模与微调机制不明**：模型变大后鲁棒性是否持续改善？指令微调（instruction tuning）究竟带来的是敏感性与鲁棒性的共同提升，还是此消彼长？

## 核心贡献（创新点）
1. **首个面向数学推理因果行为测试的形式化框架**：构建了一个区分人类正确推理路径（经抽象算子→数值→答案）与模型黑箱潜在虚假路径（文本表面、数值直接到预测）的因果图，为后续行为评估提供统一理论基础。
2. **同时量化敏感性（TCE）与脆弱性（DCE）的度量体系**：通过总因果效应（TCE，反映正确响应能力）与直接因果效应（DCE，反映受无关输入干扰的脆弱性）的分离，给出鲁棒性/敏感性的一体化刻画。
3. **设计四类可计算 do 干预并推导对应因果效应**：对操作数 N 做保持/改变答案的干预、对文本模板 T 做改变/不改变运算符的干预，借助 do-calculus 推导 DCE/TCE，使不可直接观测的虚假相关路径被显式量化。
4. **在 13 个模型上系统化实证：GPT-3 Davinci 出现鲁棒性与敏感性同步跃升**：揭示大规模预训练 + PPO 指令微调（Davinci-003）带来质变，而单纯增大参数或 LLaMA 式 Alpaca 微调并未给出同样幅度的增益，挑战"纯缩放决定一切"的简单叙事。

## 方法详解
- **问题形式化**：每个数学应用题 MWP 表示为 $Q = (T, N)$，其中模板 $T = (O, S)$ 含运算符集合 $O$ 与无关文本表面 $S$；真值 $g = f_O(N)$ 由算子作用于操作数得到。模型输出预测分布 $\mathbb{P}(R \mid T, N)$。
- **因果图设计**：图中包含节点 $T, S, O, N, G, R$。人类合理路径为 $T \xrightarrow{O} G \xrightarrow{} R$ 与 $N \xrightarrow{} G \xrightarrow{} R$（绿色子图 $\mathcal{G}_h$）；红色箭头表示模型可能学习的虚假路径 $S \to R$ 与 $N \to R$（绕过 $G$）。
- **干预类型**：(1) 直接干预所有操作数 $N_i$；(2) 对模板 $T$ 做部分可控干预——要么同时改变 $S$ 与 $O$，要么仅改变 $S$ 保持 $O$ 不变。
- **度量定义**：
  - 总因果效应 $\mathrm{TCE}(X \to R) = \mathbb{E}[\delta(P, P')]$，反映变量 $X$ 对所有路径的总影响；
  - 直接因果效应 $\mathrm{DCE}(X \to R)$ 在控制中间变量（如固定 $G$ 或 $O$）后测得，代表不经过合法推理路径的"捷径"影响。
- **两种具体 $\delta$ 度量**：
  - 预测变化 $\delta_{cp} = \mathbb{1}(r \ne r')$，关注最可能输出是否变更；
  - 相对置信度变化 $\delta_{rcc} = \frac{1}{2}(\Delta_{rel} + \Delta'_{rel})$，关注模型对正确/新正确答案的概率再分配。
- **具体因果效应**：$\mathrm{DCE}(N \to R)$ 衡量模型对"数值改变但答案不变"的脆弱性（越低越鲁棒）；$\mathrm{TCE}(N \to R)$ 衡量模型对"答案改变"的敏感性（越高越敏感）；类似地 $\mathrm{DCE}(S \to R)$ 与 $\mathrm{TCE}(T \to R)$ 刻画文本表面与整体模板的影响。
- **数值空间与归一化**：操作数取值 $\{1,\dots,C\}$，取 $C=300$ 使数字均为单 token；概率分布对 $\{1,\dots,300\}$ 归一化以计算 $\mathbb{P}(R=r)$。

## 实验与结果
- **数据集**：ASDiv-A、MAWPS、SVAMP，共筛选 437 个双操作数、307 个三操作数模板；每个模板生成 500 个干预对（大模型受预算限制使用 20 个），结果对 3 个种子平均。
- **模型**：GPT-2 系列（distilled/small/medium/large/XL）、GPT-Neo 1.3B/2.7B、GPT-J-6B、GPT-NeoX-20B、GPT-3 Instruct/Curie/Davinci-002/Davinci-003、LLaMA-7B/13B/30B 及 Stanford Alpaca（基于 LLaMA-7B）。
- **关键结果（双操作数）**：
  - GPT-J-6B 与 GPT-NeoX-20B 出现 TCE 比 DCE 分别高 30 倍与 1000 倍的现象，说明大规模预训练显著提升敏感性，但 $\delta_{cp}$ 维度上对结果保持扰动仍与结果改变干预相近，**鲁棒性未同步提升**。
  - **GPT-3 Davinci-003（175B, PPO 微调）**呈现最显著跃升：$\mathrm{DCE}_{rcc}$ 与 $\mathrm{TCE}_{rcc}$ 差距达 84%，$\delta_{cp}$ 维度下直接效应与总效应相差 76%——在大模型中首次实现敏感性与鲁棒性的同步改善。
  - 对非指令微调模型，无关文本表面 $S$ 的直接效应低于数值 $N$ 的直接效应；而 GPT-3 Davinci-00x 出现反转，即对文本表层变化更敏感。
- **LLaMA 系列扩展**：7B→30B 随参数增加 TCE-DCE 差距扩大，印证规模是重要驱动力，但 LLaMA-20B 的差距（5.2%）不及 LLaMA-7B（9.0%），说明不同架构/训练分布下的增益并不单调；Alpaca 微调虽使鲁棒性略升，但敏感度下降，整体提升有限。
- **三操作数难题**：对 Davinci-003，$\mathrm{DCE}_{cp}(N\to R)$ 从 0.17 升至 0.87，即在保持答案不变的数值扰动下，87% 的情况模型会错误改变预测，说明复杂度上升时即使最强模型也会显著退化。
- **与准确率的相关性验证**：Pearson 分析显示准确率（accuracy@10）与 $\mathrm{TCE}(N)$、$\mathrm{TCE}(T)$ 正相关（0.24、0.49），与 $\mathrm{DCE}(N)$、$\mathrm{DCE}(S)$ 负相关（-0.26、-0.36），佐证度量体系的语义合理性。

## 相关工作脉络
- **Patel et al., 2021 (SVAMP)**：早期揭示 LLM 可通过表面模式"作弊"解数学题，本文在此基础上提供原则化的因果度量，从定性反例走向可量化、可分解的行为画像。
- **Finlayson et al., 2021**：对句法一致性的因果分析，思路相近（do 干预 + 因果效应），但本文首次将因果框架系统应用于数学推理的鲁棒性评估。
- **Vig et al., 2020 / Meng et al., 2022**：通过因果中介分析探查模型内部表示与事实关联，属于模型解释学路线；本文聚焦输入空间的结构化扰动与行为输出的因果解耦。
- **Cobbe et al., 2021; Wei et al., 2022b (CoT)**：提升数学推理性能的工作；本文不提出新算法，而是提供评估这些方法真实数学能力的诊断工具。
- **Feder et al., 2021b (CausaLM)**：利用反事实语言模型做解释；本文与之一致地采用 Pearl 因果范式，但目标从解释转向鲁棒性行为的系统量化。
- **Mishra et al., 2022b (NumGLUE) / Welleck et al., 2022 (符号脆性)**：指出 LLM 符号推理的脆弱性；本文通过因果分解明确脆弱性的来源路径（数值捷径 vs. 文本捷径 vs. 算子缺失）。

## 局限性与未来方向
- **训练数据污染风险**：框架假设测试题未在训练中见过，但 LLM 训练体量巨大，难以保证完全未过拟合；作者也在 Limitations 中明确承认这一点。
- **数值范围与语言受限**：操作数限定为 $[1,300]$ 整数，无法覆盖真实场景中更大、分数、负数等情形；且仅限英语，跨语言泛化未知。
- **GPT-3 API 约束**：OpenAI 仅允许返回 top-k 概率，导致 $\delta_{rcc}$ 存在近似与下界估计，部分指标标有星号（∗）。
- **运算符干预的间接性**：由于无法在不改变表面文本的前提下仅修改 $O$，$\mathrm{TCE}(O\to R)$ 只能通过 $\mathrm{TCE}(T\to R)$ 与 $\mathrm{DCE}(S\to R)$ 的差值间接推断，精度受限。
- **未来方向**：推广至更复杂的数学表示（程序、符号表达式）、其他语言、以及针对推理过程（而非仅最终答案）的因果评估；探索基于强化学习/数学专用指令微调能否进一步突破复杂度瓶颈。

## 研究启发与可借鉴点
- **因果图 + 行为测试的统一范式**可用于其他 NLP 子领域（如常识推理、代码生成、表格推理），通过明确建模"理想路径 vs. 捷径路径"实现对模型能力的细粒度体检。
- **TCE/DCE 双指标分离**是一种简洁而信息密度高的评估思路，建议迁移到数值理解、指令跟随等任务的评估中，用以区分"真正能力"与"表面拟合"。
- **LLaMA + Alpaca 的负向结果提示**：并非所有指令微调都能提升数学推理质量，后续研究可对比不同指令分布（数学推理优先 vs. 通用对话优先）对 TCE/DCE 轨迹的影响，形成"训练数据质量 > 单纯规模"的经验依据。
- **三操作数实验中 Davinci-003 的崩溃**强烈提示：当前最强模型的"数学能力"仍建立在简化场景之上；可借鉴本文的干预设计，系统绘制模型能力随问题复杂度衰减的相变曲线。
- **Pearson 相关性验证环节**提供了一种自洽性检验模板——任何新提出的鲁棒性度量都应与其主任务准确率呈现预期方向的相关，可作为方法学论文的必要基线。

## 关键术语表
**TCE（Total Causal Effect，总因果效应）**：输入变量经由所有可能路径对模型预测产生的总体影响，反映模型的敏感性；越大说明模型越能随问题实质变化调整输出。

**DCE（Direct Causal Effect，直接因果效应）**：在控制中介变量（如答案 $G$ 或算子 $O$）后，输入变量对预测的直接影响，代表绕过正确推理链的虚假相关性；越小代表模型越鲁棒。

**do 干预（do-intervention）**：基于 Pearl 因果框架的操作，强制将某变量设置为指定值，切断其所有入边，从而识别该变量的因果效应而非相关关系。

**数学应用题（Math Word Problem, MWP）**：将算术运算嵌入自然语言情境的问题，由模板 $T$ 与操作数 $N$ 组合生成，是本文评估语言模型数学推理的基准任务形态。

**RCC（Relative Change in Confidence，相对置信度变化）**：以正确预测概率的相对增减均值刻画的度量，比硬判预测是否改变更敏感地反映模型内部概率分布的再分配。

**$\delta_{cp}$（Change in Prediction）**：干预前后模型最可能输出是否改变的二值指标，衡量预测层面的稳定性。

**指令微调（Instruction Tuning）**：使用人类编写的"指令-输出"对进一步微调预训练语言模型，使其更好地遵循人类意图；本文比较其对鲁棒性的实际增益。

**Emergent Abilities（涌现能力）**：指在大尺度模型中突然出现、在小尺度模型中不存在的技能；本文发现 GPT-3 175B 在鲁棒性与敏感性上的跳跃与此假说部分一致但需结合训练过程综合解释。

## 可复现要素
- **数据集**：ASDiv-A、MAWPS、SVAMP（均为公开数据集，MIT 等许可）；提示模板生成脚本与干预对构造细节见附录 A。
- **代码/权重**：论文未声明开源代码仓库，但使用 HuggingFace Transformers 访问 GPT-2/Neo/J/NeoX/LLaMA；GPT-3 通过 OpenAI API 调用。
- **关键超参**：数值空间上界 $C=300$，每模板生成 500 个干预对（大模型 20 个），3 次随机种子平均，top-k 概率取值上限约 100（受 API 限制）。
