# 论文速读：Synthetic-Text-Generation-with-Differential-Privacy-A-Simple

## 一句话总结
本文提出了一种仅基于 DP-SGD 微调预训练自回归语言模型的简洁方案，在提供强差分隐私（ε=4）保证的前提下，生成的合成文本在下游分类任务与分布相似度上均可与原始数据或非私有生成方案持平，证明了“隐私微调生成器+后处理采样”可作为工业级隐私数据工厂的实用范式。

## 研究问题与动机
- NLP 模型易 Memorize 训练数据，面临成员推断与数据重建等隐私攻击， tightening 的法规（如 GDPR）要求提供形式化隐私保证。
- 现有 DP 文本处理方法多为单样本扰动（token/sentence 级），无法保证“无论某样本是否存在于数据集中，输出分布均统计不可区分”的数据集级隐私要求，且存在可链接性风险。
- 直接对下游判别模型进行 DP 训练时，隐私预算随任务迭代而累积消耗；若能先生成一次性消耗的隐私合成数据，后续可无限复用下游任务而不增加泄露。
- 前序 DP 文本生成工作（如同行 Mattern et al., 2022）依赖复杂模板构造、额外 prompt-mismatch 损失，且仅在极小规模数据（25-5K）上验证，缺乏百万级数据上的系统实证与工业可用性检验。

## 核心贡献（创新点）
1. **提出极简 DP 文本生成配方**：仅用标准 DP-SGD 微调预训练 LM，无需模板构造或额外损失设计；与同期工作相比省去了 prompt 对齐开销，工程可复现性更强。
2. **系统验证规模效应与效用保持**：首次实证 GPT-2 系列模型随规模增大，DP 微调后的合成文本质量持续提升；GPT-2-Large ε=4 生成的 100K 合成数据训练的下游分类器准确率仅比原始数据低 2-4%，且仅需小样本即可媲美直接在全量私有数据上 DP 训练的任务模型。
3. **揭示 DP 文本生成的长度截断效应**：发现 DP 训练会导致自回归生成序列普遍短于非 DP 对照组与原始数据，该现象在模型增大时缓解但未消除，为后续隐私生成质量分析提供了新观测维度。
4. **构建多维压力测试评估体系**：引入 Canary 注入实验量化 PII 泄露上限，结合 F1/FID/MAUVE、主题分布（BERTopic）与长度分布进行综合评测，明确了 DP 在“保护个体隐私”与“保留群体分布/长尾模式”之间的权衡边界。

## 方法详解
- **核心流程**：以预训练自回归 LM（GPT-2/GPT-2-Medium/GPT-2-Large）为基底，采用 DP-SGD 在全量私有数据上进行监督微调；利用 DP 的**后处理不变性**，训练完成后直接采样生成合成文本，该阶段不消耗额外隐私预算。
- **条件控制生成**：借鉴 Ctrl 思路，将属性控制码（如 `Business Type: Bar | Review Stars: 5.0`）拼接至样本前缀，使模型学习条件分布：
  $$\mathbb{P}(x|c) = \prod_{i=1}^{n} \mathbb{P}(x_i | x_1, \ldots, x_{i-1}, c)$$
  生成时按原始类别分布采样 control code，从而保留数据的联合分布结构。
- **隐私机制**：采用梯度裁剪（Clip norm=1.0）限制单样本贡献，叠加高斯噪声更新；隐私预算设定 ε=4，δ=1/(N·log N)，通过数值组合算法（Numerical composition）精确计算噪声尺度。
- **采样策略**：top-k（k=50）与 nucleus sampling（top-p=0.9）结合，单次生成 100K 条合成样本用于下游评估。
- **损失函数**：沿用标准语言建模交叉熵损失，无额外正则或对抗项，整体由 Opacus 框架自动追踪隐私账本。

## 实验与结果
- **数据集**：Yelp Open Dataset（1.9M 评论，10 类商家，1-5 星）；微软内部客户反馈数据集（1M 条，含 3 个属性 A1/A2/A3）。
- **下游任务基线**：RoBERTa-base 分类器，分别以原始数据、非 DP 合成数据、DP 合成数据为训练集，在相同测试集上评估。
- **主要结果**：
  - **Table 1**：GPT-2-Large ε=4 生成数据的 Rating/Category 分类准确率（0.6936 / 0.7568）接近非 DP 对照组（0.7090 / 0.7576），且显著优于小模型 DP 生成结果。
