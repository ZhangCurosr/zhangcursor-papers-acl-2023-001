# 论文速读：Robust-Multi-bit-Natural-Language-Watermarking-through-Invariant-Features

## 一句话总结
本文提出一种基于文本不变特征（关键词与句法依赖）的自然语言多比特水印框架，通过选择对轻微篡改具有不变性的特征作为嵌入锚点，并结合专门训练的抗干扰填充模型，显著提升了水印的鲁棒性。

## 研究问题与动机
1. **现有深度水印方法鲁棒性不足**：AWT 在高比特数嵌入时提取易出错，ContextLS 虽实现零误码提取但未考虑抗篡改场景，缺乏对鲁棒性的系统研究。
2. **载荷与鲁棒性难以兼顾**：传统规则方法载荷低且语义质量差，近期深度学习方法在抗干扰能力上仍显脆弱。
3. **自然语言中缺乏类似图像的"感知显著成分"**：图像水印可将信息嵌入感知重要区域，但文本修改每个词的影响更显著，需找到替代方案。
4. **实际应用场景需求迫切**：订阅媒体、网络小说平台和大型语言模型生成内容的版权保护与泄露追踪需要可靠的水印系统。

## 核心贡献（创新点）
1. **提出基于不变特征的鲁棒水印框架**：将水印嵌入语义或句法层面的不变特征附近，使嵌入位置对轻微篡改保持鲁棒；与 ContextLS 等无不变性设计的方法本质不同。
2. **系统分析与验证两种不变特征**：通过实证研究证明关键词（Keyword）和句法依存（Syntactic Dependency）均可作为有效锚点，其状态恢复鲁棒性 $\mathcal{R}_{g_1}$ 达到 0.92+，远超 ContextLS 的 0.65。
3. **设计抗干扰填充模型（Robust Infill）**：通过最小化原始序列与污染序列输出分布的 KL 散度训练填充模型，显著提升 Phase 2 的鲁棒性 $\mathcal{R}_{g_2}$；与直接使用预训练模型的方法形成对比。
4. **使用反向 KL（Reverse KL）损失并调整掩码策略**：采用 reverse KL 避免预测分布"zero-forcing"，同时使用与测试阶段一致的掩码策略而非随机掩码，提升训练-测试一致性。

## 方法详解
**框架整体结构**：分两个阶段——Phase 1 从文本 X 提取状态 S（即掩码位置），Phase 2 利用填充模型生成水印文本。

**Phase 1：掩码位置选择**
- **关键词组件**：使用 NER 模型提取专有名词，结合 YAKE 算法提取语义核心词，以关键词为锚点选择相邻词作为掩码位置。
- **句法依赖组件**：使用 Spacy 构建依存解析树，按 NLI 蕴含分数对依赖类型排序，从高到低依次掩码直到达到目标掩码数，确保不掩码关键词。
- 鲁棒性定义：$\mathcal{R}_{g_1} = \mathbb{E}[\mathbb{1}(S = \tilde{S})]$，衡量污染前后状态一致的概率。

**Phase 2：水印编码**
1. 对每个掩码位置使用填充模型获取 top-$k_1$ 候选词。
2. 过滤标点、子词、停用词，选取 top-$k_2$ 并按字母序排序。
3. 对所有掩码位置的候选词集合做笛卡尔积生成候选水印集合。
4. 筛选满足 $g_1(X_{wm}) = g_1(X)$ 的有效水印，为每个有效水印分配比特消息。
- Phase 2 鲁棒性：$\mathcal{R}_{g_2} = \mathbb{E}[\mathbb{1}(g_2(X,S) = g_2(\tilde{X}_{wm}, \tilde{S}))]$。

**抗干扰填充模型训练**
- 使用 reverse KL 散度作为一致性损失：$\mathcal{L}_{con} = \sum_{i \in S} \text{KL}(\tilde{p}_i \| p_i)$，其中 $p_i$ 来自冻结参数的填充模型，$\tilde{p}_i$ 来自污染序列。
- 构建稀疏目标分布：只对 top-$k_1$ 词保留概率，其余置零后归一化。
- 使用与测试相同的掩码策略（关键词+句法依赖排序）进行微调，而非预训练时的随机掩码。
- 使用 TextAttack 在独立训练集上生成三种污染样本（删除、插入、替换），污染比例 2.5%~5%，并用 sentence transformer 过滤语义相似度 < 0.98 的样本。

## 实验与结果
**数据集**：IMDB（电影评论）、Wikitext-2（维基百科文章）、Dracula 和 Wuthering Heights（小说）。

**评估指标**：比特每词（BPW）、误码率（BER）、蕴含分数（ES）、语义相似度（SS）、人工评估流利度与语义保持。

**主要结果**：
- **鲁棒性提升**：在四个数据集、三种污染类型、两个污染比例下，所提方法平均 BER 较 ContextLS 提升 **+16.8 个百分点**。
- **IMDB @ CR=0.025**：Syntactic 组件 BER 分别为 D:0.100, I:0.153, S:0.133；+RI 后进一步降至 D:0.074, I:0.106, S:0.110；ContextLS 对应值为 0.219/0.303/0.273。
- **载荷**：+RI 模型在 IMDB 达到 BPW=0.144，优于 ContextLS 的 0.100。
- **语义质量**：ES/SS 虽略低于 ContextLS，但显著优于 AWT 和传统方法；人工评估中流利度变化与 ContextLS 相当。
- **效率**：嵌入 1000 句 IMDB 耗时 4 分钟，比 ContextLS 快 20 倍以上。

**最强结果**：Dracula 数据集 @ CR=0.025 删除污染下，+RI 方法 BER 仅 0.030，而 ContextLS 为 0.201。

## 相关工作脉络
1. **ContextLS (Yang et al., 2022)**：算法化嵌入/提取实现零误码，但高鲁棒性不足；本文在其基础上引入不变特征与抗干扰填充模型。
2. **AWT (Abdelnabi & Fritz, 2021)**：端到端编码器-解码器架构，但高载荷下易出错且语义质量退化；本文避免完全依赖神经网络。
3. **早期规则水印 (Topkara et al., 2006; Atallah et al., 2001)**：基于同义词替换和句法重构，载荷低且语义质量差。
4. **图像水印 (Cox et al., 1997; Zhu et al., 2018)**：启发本文"嵌入感知显著成分"的思想，但需适配文本特性。
5. **隐写术 (Fang et al., 2017; Ziegler et al., 2019)**：侧重隐蔽性而非鲁棒性，允许任意生成覆盖文本，约束较弱。
6. **LLM 水印 (Kirchenbauer et al., 2023; He et al., 2022)**：零比特水印用于检测机器生成文本，无法嵌入多比特信息。

## 局限性与未来方向
1. **语义质量与鲁棒性的权衡**：自动语义指标略低于 ContextLS，是感知性与鲁棒性权衡的自然结果。
2. **污染模拟的局限性**：使用对抗攻击技术模拟污染，可能无法完全反映真实攻击者的行为。
3. **未测试对改写的鲁棒性**： paraphrasing 可能大幅改变句法结构，因可控性差而未实验。
4. **句法组件对删除敏感**：在更高污染率（CR=0.1）下，删除操作的鲁棒性下降最快。
5. **NLI 指标的局限性**：自动指标可能忽略某些语义变化（如并列连接词的替换）。

## 研究启发与可借鉴点
1. **不变特征作为嵌入锚点的思路可迁移**：将"寻找对扰动不变的特征区域"这一图像水印理念适配到文本领域，为其他文本鲁棒性任务提供启发。
2. **抗干扰模型训练策略**：reverse KL 损失与训练-测试掩码一致性设计，可用于其他需要抗扰动的文本生成任务。
3. **依赖排序的自动化发现**：使用 NLI 蕴含分数对句法依赖排序的方法，可推广到其他需要选择替换位置的任务。
4. **高效嵌入/提取的效率优势**：算法化方法避免了 ContextLS 的迭代搜索，为实时水印应用提供了可行方案。
5. **多数据集跨风格验证**：使用 IMDB、Wikitext-2 和两部小说验证方法的通用性，实验设计值得借鉴。

## 关键术语表
**Watermarking**：将秘密信息嵌入载体内容中以实现版权保护或泄露追踪的技术。
**Payload (BPW)**：比特每词，衡量水印嵌入的信息量。
**Robustness (BER)**：误码率，衡量从污染文本中正确提取水印的准确性。
**Invariant Features**：对轻微篡改保持不变的文本特征，如关键词和句法依赖结构。
**Infill Model**：掩码语言模型，用于预测被掩码位置的替换词。
**Reverse KL Divergence**：反向 KL 散度，用预测分布加权，避免模型输出过度集中的分布。
**NLI (Natural Language Inference)**：自然语言推理，用于评估文本间的蕴含关系分数。
**TextAttack**：用于生成文本对抗样本的开源框架。
